01 · Design Vision
Ignition
Why carbon black and brake-caliper orange communicate exactly what a spare-parts shop owner needs to feel at 7am on a Monday.

Aurora — the system we are replacing — was a dark navy dashboard trying to look like fintech software. Deep blue-black (#080c14), a cool teal accent, soft glassmorphism. It is competent, but it is generic: it could be a banking app, a logistics app, a CRM. Nothing about it says auto parts. And because the shop owner's mental model of quality software is "did it change," a navy-to-navy restyle reads as nothing happening at all.

Ignition starts from the object, not the industry template. A brake caliper is painted safety orange for one reason: so a mechanic can find it instantly, under a car, in bad light, in a hurry. That is precisely the job this dashboard does all day — surface the number that matters (today's negative P&L, the client with 91 overdue days, the part at zero stock) inside a wall of otherwise-neutral data. Carbon black is not a mood, it's a canvas: matte, low-glare, the color of a tool bench, the color of a dashboard cluster at night. Orange is not a brand color, it's an alert color repurposed as the single accent — used sparingly enough that when it appears, it means "look here."

Typography reinforces the same idea. Plus Jakarta Sans, tightened to −0.04em tracking, gives headings a machined, slightly technical edge — closer to a dashboard cluster typeface than a SaaS marketing font. Inter carries body copy because it disappears at small sizes, which matters across dense tables of parts and invoices. JetBrains Mono is reserved exclusively for tabular numerals — prices, quantities, aging buckets — so every column of digits lines up like a parts catalog, not like prose.

Shape follows the same restraint-with-one-exception logic: cards are borderless, separated only by layered shadow and a one-shade surface shift (carbon → surface → elevated), at a generous 16px radius that reads as confident rather than playful. The one place geometry gets sharp is status: pill badges, hard accent underlines, a 2px orange rail on the active nav item — precision marks, not decoration.

The result should be unmistakable in a screenshot from across the room: if it isn't carbon black with one orange accent and machined type, it isn't Ignition. That is the bar for "impress me" — not a new color variable, a different application.

11 · Iconography
Stroke Style & Reference Set
A single geometric stroke family used across all three platforms — no filled icons except status dots and the active-state accent fill.

Stroke Specification

Grid24×24px artboard, 20×20 live area, 2px safe margin
Stroke weight1.75px at 24px size (scales proportionally: 1.5px at 20px, 2px at 32px)
CornersRound joins and round caps throughout — no mitered/sharp joins
FillNone by default (stroke-only); accent-filled variant reserved for active nav state and status dots
Color (dark)#A1A1AA default, #FAFAFA on hover/active label, #F97316 when representing the active/selected icon
Color (light)#52525B default, #111114 hover/active label, #EA580C active icon
Optical sizes14px (inline/table), 16px (buttons), 20px (nav rail), 28px (empty-state illustration accents)
Reference 12-icon set

React web renders these as inline SVG (existing CockpitIcons.js icon map is restructured 1:1 to this stroke spec). WPF uses the same paths as Path geometry resources in the replacement resource dictionary. React Native renders via react-native-svg with the identical path data — one icon source of truth, three renderers.

Chart Palette, Gridlines & Empty States
Charts sit on the surface (#131316) or elevated (#1B1B1F) layer, never directly on carbon — this keeps gridlines legible without raising overall screen brightness.

Gridline & Axis Rules

Gridlines#1B1B1F on surface panels, 1px, horizontal only (no vertical gridlines on time-series)
Axis labelsJetBrains Mono 8px, #6B6B74, right-aligned on Y, centered on X
Zero line#26262B, 1px solid (never dashed — dashed is reserved for forecast/projection)
Area fillLinear gradient, series color at 35% opacity → 0% opacity over the chart height
Data point4px radius, carbon fill + 2.4px series-color stroke; peak point 5px + label callout
TooltipElevated surface (#1B1B1F), L2 shadow, 8px radius, JetBrains Mono value
Applied example — stacked aging bar + empty state

Empty states never show a literal blank panel: a muted icon (stroke #3A3A42 on #1B1B1F) plus a one-line explanation and, where relevant, a primary CTA in orange. This applies identically to the Dashboard sales trend, Client Workspace invoice table, and any report-builder chart with zero rows.

Implementation notes for the platform agents

React web (dev-web-react): replace the :root block in styles.css wholesale with the --ig-* variables above; component class names (.ck-*) can stay, only the token values and a handful of radius/shadow rules need to change given the app already reads from CSS custom properties.

WPF (dev-desktop-wpf): a new IgnitionTheme.xaml resource dictionary replaces whichever theme is currently merged in App.xaml; keys above are exact 1:1 replacements for existing brush/geometry keys so styles/templates referencing DynamicResource repaint without template rewrites where structure is unchanged.

React Native (dev-mobile-rn): export the same values as a flat theme.js object; bottom-tab layout and 44px touch targets are the only intentional deviations from the desktop spec, called out explicitly on page 11.
